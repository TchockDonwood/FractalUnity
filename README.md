# Универсальный фрактал Коха

Интерактивное приложение на Unity для визуализации обобщённой снежинки Коха
с настройкой формы, угла выступа и итераций в реальном времени.

## Возможности

- **Снежинка Коха** на базе правильного N-угольника (3–30 сторон).
- **Параметрический угол выступа** (0–180°) с запретом «ломающего» диапазона 61–119°.
- **Рекурсивное построение** с числом итераций 0–6 (до 4⁶ = 4096 сегментов на сторону).
- **Зум колесом мыши** с фиксацией точки под курсором.
- **Панорамирование** перетаскиванием левой кнопкой мыши.
- **Мгновенные изменения** — все параметры применяются без перезапуска.
- **Анимация итераций** (кнопка-переключатель, цикл 0↔6).
- **Автобутстрап сцены** — интерфейс и фрактал создаются из кода, ручная сборка сцены не требуется.

## Управление

### Элементы интерфейса (панель справа)

| Элемент | Диапазон | По умолчанию | Назначение |
|---|---|---|---|
| **Итерации** | 0–6 | 3 | Глубина рекурсии |
| **Сторон** | 3–30 | 3 | Число сторон базового N-угольника |
| **Угол** | 0–180° | 60° | Угол выступа (61–119° заблокированы) |
| **Длина** | 100–800 | 400 | Диаметр описанной окружности |
| **Толщина** | 0.5–10 | 2 | Толщина линий |
| **Сброс** | — | — | Возврат всех параметров и вида к значениям по умолчанию |
| **Центр** | — | — | Сброс зума и панорамирования |
| **Анимация** | — | Выкл | Вкл/выкл автоциклическую смену итераций |

### Мышь

| Действие | Результат |
|---|---|
| **Колесо** | Зум (точка под курсором остаётся на месте) |
| **ЛКМ + перетаскивание** | Панорамирование |
| **Клик по панели** | Не запускает перетаскивание (UI перехватывает) |

## Архитектура проекта
```
Assets/
├── Scripts/
│ ├── KochCurveGenerator.cs — чистая логика генерации (без UnityEngine)
│ ├── KochCurveRenderer.cs — обёртка над LineRenderer с буфером
│ ├── FractalController.cs — связывает UI ↔ генератор ↔ рендер, зум/пан
│ ├── FractalAnimator.cs — корутина автосмены итераций
│ ├── MouseHelper.cs — абстракция над Input Manager / Input System
│ └── FractalAppBootstrap.cs — автопостроение камеры, Canvas и UI
└── Editor/
└── WindowsBuilder.cs
```

### Разделение ответственности

- **`KochCurveGenerator`** — статический класс, не зависит от Unity UI.
  Легко покрывается unit-тестами.
- **`KochCurveRenderer`** — знает только про `LineRenderer`.
- **`FractalController`** — оркестратор: слушает слайдеры, вызывает перестройку,
  обрабатывает зум и панорамирование.
- **`FractalAppBootstrap`** — «одноразовый» код, собирает сцену из пустого
  GameObject'а, чтобы не требовалась ручная настройка.

## Как это работает

### Генерация фрактала

1. Строится правильный N-угольник (`CreatePolygon`), вписанный в окружность
   диаметром `length`.
2. Каждая сторона рекурсивно разбивается на 4 сегмента:
   - точки деления на 1/3 и 2/3 длины;
   - пик над серединой, высота = `tan(angle) · segLen / 2`;
   - нормаль пика направлена **наружу** многоугольника.
3. Список точек накапливается в `List<Vector2>` и передаётся в рендерер.

### Запрет углов 61–119°

При `angle → 90°` значение `tan(angle)` уходит в бесконечность — пик «улетает»
и картинка ломается. Поэтому:

- слайдер угла прилипает к **60** (если `< 90`) или **120** (если `≥ 90`);
- в генераторе дополнительно `tan` ограничивается диапазоном `[-20, 20]`
  как страховка от внешних вызовов.

### Зум и панорамирование

- Зум фиксирует точку под курсором: `_viewOffset = mouseWorld − (mouseWorld − _viewOffset) · ratio`.
- Панорамирование переводит пиксели мыши в мировые координаты через
  `orthographicSize · 2 / Screen.height`.
- Клики по UI отсекаются через `EventSystem.RaycastAll`.
